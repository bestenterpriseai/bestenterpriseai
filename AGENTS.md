# Agent Instructions

This repository is a profile and reference guide for Enterprise AI.

## Editing Rules

- Keep content practical, enterprise-focused, and security-aware.
- Prefer official sources for fast-moving tools.
- Do not add secrets, tokens, private keys, customer data, or internal credentials.
- Do not present speculative product behavior as fact.
- When documenting tools such as Codex, Claude Code, Kiro, Antigravity, vLLM, NeMo Guardrails, OpenClaw, NemoClaw, or OpenShell, verify current documentation before making strong claims.
- Keep examples safe by default: least privilege, sandboxing, logging, approval, rollback.

## Repo Purpose

The repo should cover:

- Enterprise AI architecture.
- Agentic AI and agentic organizations.
- Agentic IDEs and CLIs.
- Agent workflows, graphs, prompts, tools, skills, and routines.
- Harness engineering.
- Inference, vLLM, caching, models, and routing.
- RAG, memory, and agentic RAG.
- Security, red teaming, guardrails, and sandboxes.
- SRE for agentic AI.
- Agentic CI/CD.

## Definition of Done

For documentation changes:

- Links are valid enough to be useful.
- Claims are scoped.
- Security implications are included.
- Tables and checklists are readable.
- The README remains a strong GitHub profile landing page.
