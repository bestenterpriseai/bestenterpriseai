# Contributing

Contributions should make this repository more useful, accurate, and operationally grounded for enterprise AI builders.

## Contribution Types

- Reference architecture improvements.
- Security controls and red-team test patterns.
- Agentic SDLC patterns.
- Inference and model operations patterns.
- Tool, IDE, CLI, MCP, skill, or routine documentation.
- SRE runbooks and metrics.
- Enterprise adoption playbooks.

## Quality Bar

Every contribution should be:

- Practical for enterprise teams.
- Clear about assumptions and limitations.
- Security-aware.
- Source-linked when discussing fast-moving tools.
- Free of secrets and private data.
- Specific enough to become an implementation checklist.

## Preferred Sources

Use official docs, standards, security frameworks, vendor docs, and primary project docs where possible.

Good source categories:

- Official product documentation.
- OWASP, NIST, MITRE, CISA, ISO, cloud-provider security guidance.
- Peer-reviewed or arXiv papers for research claims.
- Project repositories and release notes.

## Style

- Use concise headings.
- Prefer checklists and tables for operational guidance.
- Avoid hype.
- Distinguish proven patterns from emerging experiments.
- Call out enterprise risks directly.
